# XHR brand assets

* `xhr-icon-1024.png` — master icon: white rounded square with a four-colour X.
* `mipmap-*/ic_launcher*.png` — legacy launcher icons (48–192 px).
* `ic_launcher_background.xml`, `ic_launcher_foreground.xml` — adaptive icon.
* `mipmap-anydpi-v26-ic_launcher.xml` — adaptive icon descriptor.

Palette: Google blue `#4285F4`, red `#EA4335`, yellow `#FBBC05`, green
`#34A853`, on white. The mark is an X, not a G, so it is distinct from Google
and from the XRV and GRV icons.
